# ACG.RIP

让梨花在 [ACG.RIP](https://acg.rip) 找番剧资源。她读站点的公开 RSS，把候选的标题、种子链接、
准确大小和发布时间拿给你看，也可以按分类（动画、日剧、综艺、音乐、合集）、发布组或发布者缩小范围；
需要时再读一页列表，补上发布者和发布组的名字。

技能只负责找，不会自己下载或订阅：下哪一个、要不要追番，都由你说了算。

## 可以这样问梨花

- “在 ACG.RIP 搜一下《葬送的芙莉莲》，只看动画分类。”
- “这些是哪个组发的？列一下发布组和大小。”
- “再往后翻一页。”
- “下 7.6 GB 那个合集。”（这时她才会交给 NipaPlay 的下载器）

## 数据来源

- RSS：`https://acg.rip/.xml?term=…`，以及 `/<分类>.xml`、`/team/<id>.xml`、`/user/<id>.xml` 和 `/page/<n>` 翻页
- 发布者与发布组名（可选）：同一路径的 HTML 列表页

只读公开页面，不登录、不读取任何账号或 Cookie。每次搜索一次请求，补名字时再多一次。

## 限制

- ACG.RIP 的 RSS 只有种子链接，没有磁力和 info hash；NipaPlay 的下载器可以直接用种子链接。
- 没有做种数，资源可能已经没人做种。
- 从标题推测的字幕组、集数、分辨率只是线索，可能猜错。
- 翻过最后一页时站点返回错误（HTTP 500），梨花会如实告诉你。
