# 動漫花園

让梨花在[動漫花園](https://share.dmhy.org)找番剧资源。她按关键词、分类或发布组查站点的公开 RSS，
把候选的标题、磁力链接、发布者、分类和发布时间拿给你看；对你感兴趣的一条，还能查大小、种子文件和文件列表。

技能只负责找，不会自己下载或订阅：下哪一个、要不要追番，都由你说了算。

## 可以这样问梨花

- “在動漫花園找找《葬送的芙莉莲》第二季 1080p 简体的。”
- “喵萌奶茶屋最近在動漫花園发了什么？”
- “这个合集有多大，里面都有哪些文件？”
- “就下第一个。”（这时她才会交给 NipaPlay 的下载器）

## 数据来源

- 搜索：`https://share.dmhy.org/topics/rss/rss.xml`（`keyword`、`sort_id`、`team_id` 参数）
- 单个帖子：`https://share.dmhy.org/topics/view/<帖子ID>_.html`
- 发布组与分类列表：`https://share.dmhy.org/topics/advanced-search`

只读公开页面，不登录、不读取任何账号或 Cookie；每个命令只发一次请求。

## 限制

- RSS 一次最多返回约 500 条，没有翻页，太多时请缩小关键词或指定分类、发布组。
- RSS 里没有大小、做种数和发布组名；大小和发布组要对单个帖子再查一次，做种情况无从得知。
- 从标题推测的字幕组、集数、分辨率只是线索，可能猜错。
- 站点改版、出现验证页或连不上时会如实报错，不会当作“没有资源”。
